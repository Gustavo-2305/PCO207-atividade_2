# OULAD

A Open University é uma universidade pública britânica que possui o maior número de alunos de graduação no Reino Unido. É a maior instituição acadêmica do país (e uma das maiores da Europa), com dois milhões de alunos matriculados desde sua fundação em 1969. Como é evidente pelo seu nome, a Open University é majoritariamente EAD.

O dataset OULAD pertence à plataforma de ensino online da Open University (também chamada de "Virtual Learning Environment (VLE)") que os estudantes utilizam para acessar à distância os conteúdos do curso, discussões em fóruns, enviar trabalhos e conferir notas, etc. O dataset consiste em sete cursos selecionados (mencionados como módulos no dataset). As diferentes apresentações são indicadas com as letras "B" e "J" após o ano, para o semestre 2 e 1, respectivamente.

Adicionamente, o dataset inclui dados demográficos, tais como localidade, idade, deficiência, escolaridade e gênero, etc.
